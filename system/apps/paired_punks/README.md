# paired-punks

Private shared project spaces for hackathon partners: share chats, prompts, results and files, kept in sync through GitHub

> **Requires Imbue Studio (beta).** PairedPunks only runs inside an Imbue Studio workspace, which is still in beta. It is not a standalone app: it relies on Studio's chat, its window manager and its connected GitHub account, so it will not run on its own from this code. Every partner needs their own Studio workspace and a GitHub account.
